# Project: Earnings Event Volatility Research

## Objective
Develop systematic earnings volatility trading strategies.

## Coding Rules
- Use Python.
- Write comments in English.
- Separate research logic and infrastructure.
- Maintain backward compatibility.
- Run unit tests after code changes.
- Never expose API keys.
- Never download paid market data without approval.
- Never commit raw market data.
- Ask for approval before git push.

## File Naming
- Use hyphens (`-`) between words in `.ipynb` filenames.
- Use underscores (`_`) between words in other filenames.

## Research Principles
- Avoid look-ahead bias.
- Avoid overfitting.
- Clearly document model assumptions.
- Distinguish empirical findings from hypotheses.
